# Diffusion Probabilistic Models for Unpaired AT-TPC Events Translation

## Installation

1. git clone this project

2. Create an environment by running

```shell
sbatch setup_env.sh
```

## Datasets
We provided data processing notebooks inside the [data](data/) folder. Sample toy datasets can be generated by the data processing notebook from the [data](data/) folder. In the [data/Fission folder](data/Fission/), both the fission data and the fission visualization can be found. See the [data folder](data/)

## Training
We need to first train two diffusion models in each domain in preparation for translation. Remember to change the dataset_path inside [trainDPM.sh](train/trainDPM.sh) to match the dataset, as well as set/adjust hyperparamters and add a tag.

```shell
conda activate dpm-pc-gen
sbatch train/trainDPM.sh
```

After training, you can find the checkpoints of models inside logs_gen folder. Paste the desired checkpoint path to [CycleDiffusion.ipynb](CycleDiffusion) notebook. Then follows the instruction inside the notebook to start translation. If attempting to look at RANSAC results for the fission data, use the [PhysicsExperiments.ipynb](PhysicsExperiments) notebook, where you can load the checkpoint, then follow the instructions.
